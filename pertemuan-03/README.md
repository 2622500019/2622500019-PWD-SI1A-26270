# pertemuan-03 - Formulir HTML Dan CSS Dasar

 ## Baseline
 
- Menggunakan hasil P2 sebagai dasar pengembangan P3.
- Menyalin `index.html` dan `img/foto-profil.jpg` ke `pertemuan-03/`.

## Implementasi Formulir 

- Elemen form yang digunakan: [form, label, input, select,textarea, button]
- Tipe input yang digunakan: [text, email, password, date, number] 
- Atribut validasi yang digunakan: [Required, Minlength, Maxlength, min, max]

## Pengujian GET dan POST 

- Hasil pengujian GET: [Data form berhasil dikirim melalui URL menggunakan method GET.] 
- Contoh URL encoding yang ditemukan: [nama=Dewa&email=dewa%40gmail.com] 
- Hasil pengujian POST: [Data form berhasil dikirim menggunakan method POST dan tidak di tampilkan pada URL.] 

## CSS Dasar 
- Selector elemen: [H1, form, p, button] 
- Selector class: [input.form] 
- Selector ID: [#about, #contact] 
- Properti CSS dasar yang digunakan: [color, background-color, font-family, font-size, padding, margin, border] 

## Pengujian dan Perbaikan 
- Galat yang ditemukan: [Tag '<style>' belum ditutup sehingga menyebabkan eror pada HTML/CSS] 
- Penyebab galat: [Tidak terdapat tag'<style>' setelah kode CSS] 
- Perbaikan yang dilakukan: [Menambahkan Tag '<style>' sebelum '</head>'] 
- Hasil pengujian ulang: [Tidak terdapat eror dan halaman dapat ditulisakan dengan baik]
