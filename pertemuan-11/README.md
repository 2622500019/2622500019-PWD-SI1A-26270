# pertemuan-11 Analisis Kebutuhan Data dan Dasar MySQL Satu Tabel

## Deskripsi 
Pertemuan 11 membahas integrasi PHP dengan MySQL menggunakan MySQLi serta penerapan operasi 
READ untuk mengambil dan menampilkan data dari basis data. Pembahasan dimulai dari pembuatan berkas 
koneksi yang dapat digunakan kembali, integrasi koneksi pada halaman utama, pelaksanaan kueri 
SELECT , 
hingga pengambilan dan penyajian hasil kueri pada halaman web. Pengembangan dilakukan secara bertahap 
dengan melanjutkan artefak dari Pertemuan 10, sehingga setiap proses integrasi, pengambilan data, dan 
penyajian hasil dapat diperiksa sebelum dilanjutkan ke tahap berikutnya.
